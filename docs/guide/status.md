# Project status

NativeScript Preact is in the planning stage. The repository and documentation are ready for discussion; the framework implementation has not started.

## Available now

- A public repository under the MIT license.
- Project branding and an overview of the intended direction.
- Documentation with design goals, a roadmap, and contribution guidance.
- GitHub issues for use cases, technical discussion, and documentation feedback.

## Still ahead

| Area | Status |
| --- | --- |
| Rendering adapter | To be investigated |
| Native elements, properties, and events | Planned |
| Hooks, context, refs, and component lifecycle | Planned |
| TypeScript and JSX types | Planned |
| Navigation and modals | Planned |
| Development tooling and app templates | Planned |
| Installable release from this project | Not available |

The table describes the intended scope. It does not promise an API, a release date, or compatibility with a particular framework version.

## What to expect next

The first technical milestone is a small rendering prototype. It should show that a component can create a native view, update it after a state change, respond to an event, and clean up correctly.

That work will help determine the architecture before the project expands into navigation or development tooling. See the [roadmap](/project/roadmap) for the proposed sequence.

## Following progress

The [repository](https://github.com/rafaelaugustos/nativescript-preact) is the source of truth for implementation work. Use [issues](https://github.com/rafaelaugustos/nativescript-preact/issues) to discuss requirements and open questions.

Installation instructions and version support will be documented when this project has a release to evaluate.
